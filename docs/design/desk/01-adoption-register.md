# Desk adoption register: what we take from each repository, per capability

Status: design input for the Agent Spend and Worth Desk on the Plumbline core. Date: 2026-10-20. Built only from profiles 57 to 90 in `docs/design/prior-art/profiles/` and the format of `99-synthesis-best-of-by-module.md`. Nothing here is built or measured. Each row is an adoption decision with a gate; a gate that does not pass means the item is not claimed.

How to read a row. **ID** is stable and is meant to be cited by the Desk spec and its blueprints. **Source** gives the profile number as `P<nn>` and the path:line exactly as the profile writes it (paths are relative to that profile's repository; where two repositories share a file name the profile's folder is kept). **Licence** is one of: *reuse with credit* (MIT or Apache 2.0 text; copy with credit and notice, rebuilt in TypeScript anyway) or *mechanism only* (rebuild from the idea, copy no code). **Copy exactly** is the rule or shape to reproduce. **Avoid** is what the profile says not to take. **Flaw to fix** is a defect the profile found in that source that the Desk must not inherit. **Gate** is the test that must pass before the row counts. Anything a profile marks NOT VERIFIED stays NOT VERIFIED here. Where a row says "Desk addition", the content is our design and is not in any profile.

Licence rule applied throughout, from the profiles. MIT and Apache 2.0: reuse with credit. Exceptions: `enterprise/` in litellm (P61, separate commercial licence) and `ee/` folders in Langfuse (P69, separate licence): mechanism only. Elastic License 2.0 (Phoenix, P71) and AGPL-3.0 (dedrift, P76; coder/coder, P86): mechanism only. `coder/boundary` (P86) is MIT. figuard-core (P66): Apache text, but GitHub reports NOASSERTION, so treat as Apache with that caveat. ccusage (P57): MIT by the file, GitHub reports NOASSERTION. Price data copied from litellm (P61) needs attribution and a re-check of each entry's `source`.
