## 1. What it is
A multi-package Python monorepo providing vendor-neutral OpenTelemetry instrumentation for 15+ LLM providers, 7 vector databases, agent frameworks (CrewAI, OpenAI Agents, Agno, LangChain), and MCP ([README.md:116-163](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/README.md#L116-L163)). It maintains `opentelemetry-semantic-conventions-ai` alongside the higher-level `traceloop-sdk`. Apache 2.0.

## 2. Architecture map
- **Semantic Conventions**: `packages/opentelemetry-semantic-conventions-ai/` defines enum values and attribute constants ([opentelemetry/semconv_ai/__init__.py:6-395](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-semantic-conventions-ai/opentelemetry/semconv_ai/__init__.py#L6-L395)).
- **Instrumentation Suite**: 32 distinct `opentelemetry-instrumentation-*` packages patching SDK entrypoints via `wrapt` (e.g. `openai/shared/chat_wrappers.py:10-27`, `crewai/instrumentation.py:87-95`, `mcp/fastmcp_instrumentation.py:26-39`).
- **Traceloop SDK**: `packages/traceloop-sdk/` wraps OTel TracerProvider initialization ([tracing/tracing.py:66-184](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/tracing/tracing.py#L66-L184)) and exposes user-facing workflow, task, agent, and tool decorators ([decorators/__init__.py:23-32](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/__init__.py#L23-L32)).
- **Data Flow**: Caller → decorated agent/workflow context → patched provider call → span creation with GenAI attributes → OTLP HTTP/gRPC exporter (`tracing.py:345-380`).

## 3. Features and how each behaves
- **Decorators**: `@workflow`, `@agent`, `@task`, `@tool` automatically create enclosing spans named `{entity_name}.{kind}` ([decorators/base.py:193](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/base.py#L193)) and attach `traceloop.span.kind` ([decorators/base.py:208](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/base.py#L208)).
- **Content Privacy Gating**: `TRACELOOP_TRACE_CONTENT` env var (default `"true"`) gates logging of input prompts and output completions into span attributes ([decorators/base.py:163-167](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/base.py#L163-L167)).
- **Session/Conversation Scoping**: `@conversation(conversation_id=...)` injects OTel context token for `gen_ai.conversation.id` ([decorators/__init__.py:35-54](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/__init__.py#L35-L54)).
- **Failure Behavior**: Exceptions are captured on spans via `record_exception` and status set to `ERROR` without crashing caller execution ([decorators/base.py:133-136](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/base.py#L133-L136)). Context tokens use `_safe_detach` to swallow cross-coroutine detach failures ([decorators/base.py:94-110](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/base.py#L94-L110)).

## 4. How people use it
`pip install traceloop-sdk` followed by `Traceloop.init()` ([README.md:68-78](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/README.md#L68-L78)). Or install individual instrumentation packages (e.g. `opentelemetry-instrumentation-openai`) directly in existing OpenTelemetry setups without the SDK ([README.md:58-60](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/README.md#L58-L60)). Exports standard OTLP to Datadog, Honeycomb, Dynatrace, SigNoz, Traceloop, or OTel Collector ([README.md:87-114](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/README.md#L87-L114)).

## 5. Mechanism for the Desk
- **Relation to GenAI Conventions**: In v0.5.0, OpenLLMetry migrated from legacy `llm.*` conventions to upstream OTel GenAI semantic conventions, delegating official attributes (`GEN_AI_SYSTEM`, `GEN_AI_REQUEST_MODEL`, `GEN_AI_USAGE_INPUT_TOKENS`, `GEN_AI_USAGE_OUTPUT_TOKENS`) directly to `opentelemetry.semconv._incubating.attributes.gen_ai_attributes` ([MIGRATION.md:8-46](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-semantic-conventions-ai/MIGRATION.md#L8-L46)).
- **Token Attributes**: Emits upstream `gen_ai.usage.input_tokens` and `gen_ai.usage.output_tokens`, cache reads as `gen_ai.usage.cache_read.input_tokens` ([MIGRATION.md:105](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-semantic-conventions-ai/MIGRATION.md#L105), [openai/shared/__init__.py:284-290](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai/opentelemetry/instrumentation/openai/shared/__init__.py#L284-L290)), and project-extension attributes `gen_ai.usage.total_tokens` ([semconv_ai/__init__.py:68](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-semantic-conventions-ai/opentelemetry/semconv_ai/__init__.py#L68)) and `gen_ai.usage.reasoning_tokens` ([semconv_ai/__init__.py:78](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-semantic-conventions-ai/opentelemetry/semconv_ai/__init__.py#L78), [openai_agents/_hooks.py:618](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai-agents/opentelemetry/instrumentation/openai_agents/_hooks.py#L618)).
- **Model Identity**: Emits requested model on `gen_ai.request.model` and answered model on `gen_ai.response.model` ([openai/shared/__init__.py:241](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai/opentelemetry/instrumentation/openai/shared/__init__.py#L241)).
- **Cost Attributes**: **NOT PRESENT.** OpenLLMetry contains zero cost attributes, pricing tables, or currency calculators in its codebase (search across `semconv_ai` and `traceloop-sdk` yields no cost constants). Cost computation is pushed entirely downstream to backend SaaS collectors.
- **Agent Span Hierarchy**: Top-level workflow span has `traceloop.span.kind = "workflow"` and `traceloop.workflow.name` ([tracing/tracing.py:391-393](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/tracing/tracing.py#L391-L393)). Child agent span has `traceloop.span.kind = "agent"`, `gen_ai.operation.name = "invoke_agent"`, and `gen_ai.agent.name` ([openai_agents/_hooks.py:875-879](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai-agents/opentelemetry/instrumentation/openai_agents/_hooks.py#L875-L879)). Handoffs emit spans named `{from_agent} → {to_agent}.handoff` with `gen_ai.handoff.from_agent` and `gen_ai.handoff.to_agent` ([openai_agents/_hooks.py:923-939](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai-agents/opentelemetry/instrumentation/openai_agents/_hooks.py#L923-L939)). Task spans track hierarchy via dot-chained `traceloop.entity.path` ([tracing/tracing.py:306-311](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/tracing/tracing.py#L306-L311)).

## 6. Agent patterns
Supports multi-agent handoffs with parent tracking via `_reverse_handoffs_dict` ([openai_agents/_hooks.py:868-872](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai-agents/opentelemetry/instrumentation/openai_agents/_hooks.py#L868-L872)), tool definitions captured as JSON lists ([openai_agents/_hooks.py:624-654](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai-agents/opentelemetry/instrumentation/openai_agents/_hooks.py#L624-L654)), and structured parts-based messages for `gen_ai.input.messages` and `gen_ai.output.messages` ([openai_agents/_hooks.py:371-400](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai-agents/opentelemetry/instrumentation/openai_agents/_hooks.py#L371-L400), [552-555](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai-agents/opentelemetry/instrumentation/openai_agents/_hooks.py#L552-L555)).

## 7. Model and data layer
Instrumentations extract parameters per SDK. Provider strings are standardized in `GenAISystem` ([semconv_ai/__init__.py:6-36](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-semantic-conventions-ai/opentelemetry/semconv_ai/__init__.py#L6-L36)). MCP instrumentation wraps `FastMCP` server tool execution and client SSE sessions ([mcp/instrumentation.py:91-130](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-mcp/opentelemetry/instrumentation/mcp/instrumentation.py#L91-L130)).

## 8. Hackathon-care checks
- Standard OTLP exporter (HTTP/gRPC) works out of the box ([tracing/tracing.py:345-380](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/tracing/tracing.py#L345-L380)).
- `disable_batch=True` forces synchronous span flushing for test and demo harnesses ([README.md:84](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/README.md#L84)).
- Secrets in prompts can be scrubbed by disabling content tracing (`TRACELOOP_TRACE_CONTENT=false`).

## 9. Traps seen
- **No cost data**: Expecting OpenLLMetry spans to carry USD pricing will fail; downstream calculation is mandatory.
- **Context token leaks in async**: Detaching context tokens naively across threads/coroutines causes crashes; requires defensive `_safe_detach` ([decorators/base.py:94-110](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/base.py#L94-L110)).
- **Attribute length truncation**: Long serialized tool/prompt JSON strings may be cut if `OTEL_SPAN_ATTRIBUTE_VALUE_LENGTH_LIMIT` is set ([decorators/base.py:40-48](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/traceloop-sdk/traceloop/sdk/decorators/base.py#L40-L48)).

## 10. Reuse
Apache 2.0: wrapper patterns, span taxonomy, `_safe_detach` context handling, and parts-based serialization may be copied with attribution.

  2. The agent handoff span convention (`{from_agent} → {to_agent}.handoff` with `gen_ai.handoff.*` attributes) ([openai_agents/_hooks.py:923-939](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-instrumentation-openai-agents/opentelemetry/instrumentation/openai_agents/_hooks.py#L923-L939)).
  3. Strict upstream delegation to `opentelemetry.semconv._incubating.attributes.gen_ai_attributes` for model, token, and finish reason attributes ([MIGRATION.md:18-43](https://raw.githubusercontent.com/traceloop/openllmetry/HEAD/packages/opentelemetry-semantic-conventions-ai/MIGRATION.md#L18-L43)).
- **Three things to avoid**:
  1. Relying on OpenLLMetry for spend meters or cost calculation; it does not track cost.
  2. Unbounded JSON string dumping without size validation on tool definitions.
  3. Mixing custom operation names without namespacing them against official OTel semconv.
- **Where the Desk is ahead**: The Desk pairs span token metrics directly with real-time on-span dollar pricing, budget thresholds, and verified outcome receipts, whereas OpenLLMetry remains purely an instrumentation pipe.
