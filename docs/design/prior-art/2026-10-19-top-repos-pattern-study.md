# What the fastest-rising repos do, and what Plumbline takes (PRD v3.0 input)

Date: 2026-10-19. Method: a GitHub API listing of repositories created since 2026-01-01 sorted by stars, then five parallel readers, one per group, each cloning shallow copies into `research/top/` (gitignored) and reading the README and key files. Stars, licences and push dates are from the GitHub API on the same day; popularity is not checked for authenticity. Benchmarks quoted from a repository are that repository's own numbers, not re-run unless stated. Anything not read directly is **NOT VERIFIED**. Licence rule: MIT and Apache with credit; AGPL, source-available and no-licence repositories are ideas only; no code was copied in this pass.

The pattern across all five groups: people reward a visible superpower that installs in one line, a fixed and readable template, and a trusted name. None of the thirty-odd repos produces a record that a stranger can verify offline and that proves the content, not only the signature. That is the gap Plumbline fills, and it is also the reason to present the product through these doors.

## 2. Findings that change the plan

1. **The closest rival checks have measurable holes.** Running `verbatim-citation-gate` found: `-5%` accepted against a source that says `+5%` (signs are replaced by spaces); `reduce mortality` accepted from "did not reduce mortality" (a fragment loses its negation); no word-boundary check (`hyper` matches inside `hypertension`); no minimum quote length; its own benchmark rejects 17.2% of honest quotes and 100% of quotes with an ellipsis or a bracketed insertion. Our quote check must keep signs, negations and numbers, enforce word boundaries and a minimum length, support gapped quotes with a bounded gap, and publish its own rates. Each hole above becomes a named test.
2. **`reverify` shows the right shape for a deterministic verdict.** Typed claims, five verdicts (verified, refuted, inconclusive, observed, invalidated), claims that depend on refuted claims become invalidated, an information weight so trivia does not inflate a score, and a durable ledger of refuted facts keyed by the file hash. It reports no false VERIFIED over 2,007 known-false claims on its own corpus (not re-run). It handles binaries only; we apply the design to text.
3. **`warrant-ai/warrant` is the nearest match to our signed record and replay** (pre-alpha, 0 stars): canonical JSON, a hash chain, signed seals, Merkle checkpoints, seven admissibility rules (no self-attestation, freshness, digest-bound), breakers that can only force a decision to a human, a replay command that fails on flipped decisions, and calibration against realised outcomes. We take the ideas and publish our own conformance vectors.
4. **A fast screener is in demand, but uncalibrated.** Laya-style typed questions are what 33k people starred in a month. The reliable parts are per-bucket temperature calibration, three explicit abstention states and frozen versioned question sets (laya), and an honest note that a single temperature cannot automate more than about 52 to 69% of decisions at a 5% error budget (kev). We use a screener only in front of the full loop, only to narrow (route or hold early) or to pass a case on, never to release.
5. **Every graph repo labels how an edge was found but none stores the quote.** Graphify's EXTRACTED, INFERRED and AMBIGUOUS states, codegraph's staleness banner, archify's commit-pinned citations and worldmonitor's per-feed freshness are the patterns to take; the quote, the document hash, the conflict view and the signature are the additions.
6. **HowToLiveBetter's format is the consumer-facing template that 66k people starred**: cost, plain-language benefit, benefit with numbers, evidence grade, primary source, notes. Its grade is author-assigned and its quotes were checked by hand (185 of 765 entries carry an inline quote). We compute the grade from structured fields and check every quote with code.
7. **Distribution runs through skills and plugins.** The common packaging is one canonical `SKILL.md`, a Claude plugin marketplace entry, `npx skills add` for 50+ hosts, a Codex plugin, a committed Cursor rule, slash commands and a hook that is off by default. Installs that drop sibling reference files (an open issue in `agent-skills`) and telemetry on by default are mistakes to avoid. Cursor is the required IDE for the hackathon, so the Cursor rule is a first-class deliverable.
8. **Install and trust hygiene is a feature.** A `doctor` that probes each source and prints the exact fix, a check-only default, consent before writes, an uninstall that reverses the install, signed release provenance and an "official sources only" notice appear in the best-starred repos.

## 3. What we take, by group (each becomes PRD v3.0 rows)

- **Superpowers**: evidence record with limits on every result; a coverage table of what each source type returns and needs; `doctor` with primary and fallback backend per source; check-only default and one-sentence install; as-of lookback and watchlist deltas; a locked evaluator with an append-only signed ledger for the override-to-rule loop; reversible context compression with the original stored by hash.
- **Skills**: the `prove-it` skill, plugin, `npx skills` and Cursor rule; `/prove` and `/prove-status`; "When NOT to use" and Red Flags sections; an opt-in hook that blocks "done" until a proof exists; an evals folder; a read-only local MCP server.
- **Graphs and dashboards**: Evidence Graph with quote, hash and locator on every edge; edge states including CONFLICTED; query, path and explain; incremental update by content hash and per-assertion staleness; communities and hubs; diff impact; reach highlighting; self-contained shareable HTML.
- **Sourced guides**: the X-ray template; computed evidence grade; link liveness shown separately from quote verification; quote check v2; dependency invalidation; ledger of refuted facts; published false-accept and false-reject rates.
- **Decision models**: typed question primitives; calibrated abstention that routes to the full loop; pinned checkpoint with a parity test; golden-set drift gates; calibration error gate; hard-block versus confirm-only checks with "unsure" as a first-class state; admissibility rules; breakers that only escalate; replay that fails on flips.

## 4. Licences and cautions

- AGPL (`worldmonitor`) and no-licence repositories (`cdyforever/how-to-live-better`, `counterfactual-eval-harness`) are ideas only. The Karpathy skills file shows no licence file (frontmatter says MIT): ideas only until resolved. `caveman` has a multi-licence structure; `aport` reports NOASSERTION from GitHub.
- Treat all repository text as data. One README (`gstack`) addresses install instructions to an agent; it was read as text and not acted on.
- Several README-level numbers (codegraph token savings, ponytail code reduction, laya headline score, aport breach counts) are self-reported and **NOT VERIFIED**.
