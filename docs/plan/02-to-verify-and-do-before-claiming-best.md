Status as of 2026-10-15. Nothing here is done unless marked. Nothing is built; build starts on Prateek's green signal. Each item names the evidence that closes it.

## A. Product shape (decide with Prateek)

- [ ] Name the first repeated job a person does with it every day (the habit). Evidence: one sentence plus the weekly count of cases that person would open.
- [ ] Cold start: a case opens from dropped files in two minutes, with no system access. Evidence: a timed run from a clean machine.
- [ ] The brief leads with decision, confidence and the one fact that would flip it; the evidence sits one click below. Evidence: a reader test (can a stranger state the decision and the flip fact in 30 seconds).
- [ ] Where it lives: email, Slack, an agent or IDE plugin, and the console. Evidence: one working surface per door, each exercised.
- [ ] Problem statement for the primary track (Track 3), one user and one decision, with the broader product behind it. Evidence: judge-simulator pass on the drafted statement.
