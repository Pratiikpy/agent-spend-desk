# The gateway door: a gate for tools with no hook (2026-10-24)

`desk gate gateway --upstream <url> --policy <file> [--price MODEL=IN,OUT] [--reserve MODEL=USD]` starts a loopback server that an agent can use as its OpenAI-compatible base URL (`OPENAI_BASE_URL=http://127.0.0.1:8766/v1` or the tool's own setting). Every `POST /v1/chat/completions` is reserved against the gate before it is sent, at the worst case (prompt estimate plus `max_tokens`), and settled for the tokens the upstream reports when it answers. The caller's own key is passed on and never stored or logged.

## What it does with each request

| Request | Result |
|---|---|
| Allowed by the gate | Forwarded; settled for the real usage (cached prompt tokens priced as cache reads); streams are relayed byte for byte and the gateway asks the upstream to report usage (`stream_options.include_usage`), keeping the caller's other stream options |
| Refused by the policy, over a cap, or needing approval | 403 or 429 with the gate's reason, the remaining budget and the approval request if there is one; the upstream is never called |
| A model with no price | 403 `unmetered_model`, unless the owner sets a price (`--price`) or a flat reservation (`--reserve`) |
| The policy routes the task to another model | The body's model is rewritten, and `x-desk-routed-from` says so |
| The gate cannot decide (database closed, error) | 503 `gate_unavailable`; the upstream is never called |
| Upstream error, unreachable, or silent past the first-byte limit | The reply is relayed (or 502 / 504) and the reservation is freed |
| Usage never reported, or the caller hangs up mid-stream | Settled for what was reserved, and counted as `settledAtWorstCase` |
| Any read (listing models) | Passed through and counted as `unmetered` |
| Any other write (embeddings, images, the Responses API) | 403 `unmetered_route`: it cannot be metered here, and letting it through would let money leave unseen |
| A Host header that is not the gateway's own loopback address | 421 |

## Run against the real model endpoint

The gateway was pointed at Nightshift (which fronts NVIDIA's Nemotron) with a daily cap of $0.05 and an owner price of $0.50 in and $2.50 out per million tokens for the model: a non-stream call (39 in, 3 out) settled for 27 micro-dollars; a streamed call (39 in, 4 out) settled for 30; a call to an unknown model was refused with `unmetered_model` in 20 ms; a call asking for a million output tokens (a $2.50 reservation) was refused with 429 `budget_exceeded` in 13 ms and never reached the model; listing models passed; an embeddings call was refused as unmeterable. `gate status` afterwards: six events, no open reservation, integrity ok.

## Tested

`tests/desk/gateway/gateway.test.ts` (23 cases, against a fake upstream and the real gate) covers each row of the table, the key never appearing in a record, cached tokens, a request too large, a body that is not JSON or names no model, eight simultaneous callers (no more than three allowed by a cap that fits three), session and project identity, and the money being freed in every failure. `tests/desk/virtual-prices.test.ts` covers owner prices.

## What it does not cover

- It meters one route. Anthropic's `/v1/messages`, OpenAI's Responses API (which Codex uses) and embeddings are not metered, so a tool that uses them is refused, not governed. The Anthropic-compatible route is the next one.
- A tool that ignores its base-URL setting, or is never pointed here, is outside the gateway. The gateway reports what passed through it (`stats()`), and cannot say what did not.
- Only a plain HTTP upstream on the loopback interface was exercised; TLS to a public endpoint (api.openai.com, api.anthropic.com) was not. **NOT VERIFIED** against those.
- The prompt estimate is the body's size divided by three; a request that really holds more tokens settles above its reservation, which the gate records as an overage.
- With an upstream that ignores `include_usage`, every streamed call settles at the worst case, which over-counts.
- The standing owner price for a free or plan-served model is the owner's choice, not a vendor's list price, and the snapshot says so.
