# Demo video script: desk. (3:57 of 4:00)

A captioned motion-graphic video with no voice. Every figure on screen is read out of a real run (`desk demo`, `desk enforcement`) or a committed result file (`docs/verification/`, `docs/design/desk/feature-status.json`, the clean-room logs, the signed Nightshift receipts) by `scripts/demo-video-motion/gen-data.mjs`; the script stops if a figure cannot be found, and the render stops if the film would run outside one minute and 3:58. The product screens in it are captures of the real UI (fourteen full-page captures of `desk ui --sample`, light theme). Scene lengths follow the caption reading time (about 3 words a second plus a second), and each animation is timed to the caption that names it, so a caption can always be read while its figure is on screen. Captions come in word by word.

The look is the Blank brand kit: ink on white, one green accent, rust red only for what failed or was blocked, Outfit and JetBrains Mono. The black redaction bar is the one motif: it covers the word "limit" in the first scene and it is the cut between every pair of scenes. A dot grid drifts at the edges, each scene pushes in slowly, and the number of the beat sits behind it as a pale numeral.

The first caption says the scenario is constructed. Cursor appears only as a name with "nothing is claimed beyond its log"; `docs/sponsors/cursor-usage-log.md` is empty, and Cursor became optional on 22 October 2026.

## Making it again

```
npm i --prefix scripts/demo-video-motion
node scripts/demo-video-motion/gen-data.mjs          # reads the figures from real runs and result files
cd scripts/demo-video-motion
node stills.mjs <dir> <frame> ...                    # look at chosen frames first
npx remotion render src/index.ts Demo <out.mp4> --concurrency=2 --port=3417
```

It needs Google Chrome (pass `--browser-executable` if it is not found) and about 2 GB of free memory for two render workers; a render takes about 25 minutes. The fourteen screen captures in `scripts/demo-video-motion/public/img/ui/` come from `desk ui --sample` in a light browser theme; they are constructed-sample screens, with no real history in them. Upload the result so that it plays from a logged-out browser, and check by opening the link in a private window. The older screen-recording version (`scripts/demo-video/record.mjs`) is kept; its title card says "Built in Cursor and Claude Code", which the repository does not support, so it must not be uploaded.

## What the video does not show

A live vendor pause on a tool that has no hook; a dollar figure claimed as an invoice; a "better model" claim without an interval; a regression presented as natural; a canary verdict reached in minutes (the statistic needs 28 days); the Desk presented as clearly better than a tool-using agent (the pre-registered margin is 10 of 60, at the edge of what that sample shows); any Cursor session, since none is logged. It does not show every feature: the plan critic and schema revision, the regret ledger, route replay, seat return, packs and the opt-in index, the judge panel, trajectory capture and the swap run, the policy language and the wind tunnel's method are in the README and the deck, not on screen.
