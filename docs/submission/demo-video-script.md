# Demo video script: desk. (about 3:45 of 4:00)

The video is a captioned screen recording of real runs, made by a script from the output of `npm run desk -- demo` and the live screens (`npm run desk -- ui --sample`): the terminal scenes replay the captured output line by line, the product scenes drive the real UI in a browser. Nothing on screen is typed in by hand. It has no voice; the captions below are burned in, and the narration column is what to say if you record a voiced version over it. Every figure is read off the screen; if a run differs from this script, the script changes, not the number.

Caption on the first card: "Constructed scenario. Every figure on screen is computed from it by the same code that reads your logs." The sponsor line on the title card names Cursor only because `docs/sponsors/cursor-usage-log.md` is meant to record real Cursor sessions; remove that clause if the log stays empty.

## Making it again

The recorder is outside the repository (a Node script with `playwright-core`, Chrome and ffmpeg). It runs `desk demo` first, so the scenes always show the current output. Upload the result so that it plays from a logged-out browser, and check by opening the link in a private window.

## What the video does not show

A live vendor pause on a tool that has no hook; a dollar figure claimed as an invoice; a "better model" claim without an interval; a regression presented as natural; a canary verdict reached in minutes (the statistic needs 28 days, and the card says so); the Desk presented as better than a tool-using agent (it is level with one).
