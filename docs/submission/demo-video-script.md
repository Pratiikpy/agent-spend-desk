# Demo video script: desk. (3:49 of 4:00)

A captioned motion-graphic video with no voice. Every figure on screen is read out of a real run (`desk demo`, `desk bench report --sample --set B`) or a committed result file (`docs/verification/`) by `scripts/demo-video-motion/gen-data.mjs`; the script stops if a figure cannot be found, and the render stops if the film would run outside one minute and 3:58. The product screens in it are captures of the real UI. Scene lengths follow the caption reading time (about 2.7 words a second plus a second), and each animation is timed to the caption that names it, so a caption can always be read while its figure is on screen.

The look is the Blank brand kit: ink on white, one green accent, rust red only for what failed or was blocked, Outfit and JetBrains Mono, a black redaction bar as the one motif.

The first caption says the scenario is constructed. Cursor appears only as "the required IDE", with "nothing is claimed beyond its log"; `docs/sponsors/cursor-usage-log.md` is empty until real Cursor sessions are logged.

## Making it again

```
npm i --prefix scripts/demo-video-motion
node scripts/demo-video-motion/gen-data.mjs          # reads the figures from real runs and result files
cd scripts/demo-video-motion
node stills.mjs <dir> <frame> ...                    # look at chosen frames first
npx remotion render src/index.ts Demo <out.mp4> --concurrency=1 --port=3417
```

It needs Google Chrome (pass `--browser-executable` if it is not found) and about 1 GB of free memory for one render worker; a render takes about 12 minutes. Upload the result so that it plays from a logged-out browser, and check by opening the link in a private window. The older screen-recording version (`scripts/demo-video/record.mjs`) is kept; its title card says "Built in Cursor and Claude Code", which the repository does not support, so it must not be uploaded.

## What the video does not show

A live vendor pause on a tool that has no hook; a dollar figure claimed as an invoice; a "better model" claim without an interval; a regression presented as natural; a canary verdict reached in minutes (the statistic needs 28 days); the Desk presented as clearly better than a tool-using agent (the pre-registered margin is 8 of 60, at the edge of what that sample shows); any Cursor session, since none is logged. It does not show every feature: the plan critic and schema revision, the regret ledger, route replay, seat return, the policy language and the wind tunnel are in the README and the deck, not on screen.
