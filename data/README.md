# Data sources

Nothing here is real customer data. The repository holds recordings and a price snapshot; the sample itself is generated.

| Path | What it is | Source and licence | Size | How to regenerate | Limits |
|---|---|---|---|---|---|
| `prices/anthropic-litellm-2026-10-22.json` | A dated snapshot of first-party Anthropic list prices per model | BerriAI/litellm `model_prices_and_context_window.json` (MIT), fetched 2026-10-22 | 8 KB | `npx tsx scripts/build-price-snapshot.ts` | List prices, not what a plan costs. A model missing from the file is counted as `unpriced`, never guessed |
| `sample/cassettes/` | Recorded replies: Nemotron (policy Drafter and Attacker, Ask planner and Explainer) and Zetaris SQL answers | Recorded from live runs on 2026-10-22 and 2026-10-23: `desk propose --record`, `desk ask --record`, `desk silos --record` | 20 files | Run the same commands with keys in `.env` and Zetaris running (see `docs/sponsors/zetaris-local-setup.md`) | A recording replays only the exact request it was made for; a different request is an error, never a guess. The sample ledger changes the request, so changing the sample generator means re-recording |
| `sample/engines/conformance.json` | The conformance counts of Meterless's engines, from a recorded run of Meterless's own runners | `vendor/meterless/` (Apache-2.0) | 1 KB | `npx tsx scripts/run-conformance.ts` | Counts are from the run recorded at the commit named inside the file |
| `sample/canary/runs.jsonl` | The canary series: one real model call per task, per day and arm, 30 assigned dates | NVIDIA API, `nvidia/nemotron-3.5-super-vl-120b-a12b` then `nvidia/nemotron-3.5-lightning-30b-a3b` (the switch on day 15 is deliberate), recorded by `scripts/canary-record.ts` | about 200 KB | `npx tsx scripts/canary-record.ts --days 30` with a key in `.env`; about three hours, because of rate limits | Dates are assigned; the 52 tasks and their checkers are in `src/desk/canary/tasks.ts`. The first recording, on a 16-task pack, is kept in `docs/verification/canary-first-run/` |
| `desk/sample/` (not committed) | The constructed scenario: 14 engineers, 987 sessions over two months, as Claude Code logs and five git repositories, with waste planted at known places | Generated from a seed by `src/desk/sample/gen.ts`; `truth.json` records what was planted | about 590 MB on disk (1,837 log files, the largest part), built in about 20 seconds | `npm run desk -- --sample` | Constructed, not a real team. It has planted loops, idle polling, cache misses, sub-agent fan-out, and a tool-version and model-mix change on 2026-10-14; a detector that finds them proves it works on this scenario, not on every team |

`input_examples/` and `output_examples/` hold one cleaned session in the Claude Code log format and one cleaned decision trace.
